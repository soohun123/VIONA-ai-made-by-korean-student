Google·네이버 로그인 연결
먼저 각 제공업체 개발자 콘솔에서 앱을 등록하세요. 아래 설정은 이 Windows 사용자 계정으로 암호화해 저장하며 EXE에 포함하지 않습니다.
처음 등록하는 방법
  1. Google Cloud Console에서 Google Auth Platform의 동의 화면을 구성하고 OAuth 클라이언트 유형을 데스크톱 앱으로 만드세요. 테스트 모드라면 테스트 사용자를 등록하세요.
  2. 네이버 개발자센터에서 네이버 로그인 앱을 만드세요. PC 웹 환경의 서비스 URL은 http://127.0.0.1, Callback URL은 http://127.0.0.1:43871/oauth/callback/naver로 등록하세요.
  3. 발급받은 Client ID와 Secret을 위에 저장하고 로그아웃한 뒤 해당 로그인 버튼을 사용하세요. 임의의 값을 넣으면 실제 로그인은 동작하지 않습니다.
현재 PC용 구성입니다. 다른 PC에 배포하는 공용 서비스는 네이버 Secret을 보관할 별도의 인증 서버와 서비스 검수가 필요합니다.
